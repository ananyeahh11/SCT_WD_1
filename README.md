# SCT_WD_1 - Responsive Landing Page

## Overview

This project is a Responsive Landing Page created as part of the SkillCraft Technology Web Development Internship.

The website includes an interactive navigation menu that changes style when scrolling and when hovering over menu items. The navigation bar remains fixed at the top of the page and enables smooth navigation between sections.

## Features

* Fixed navigation bar
* Scroll-based navbar color change
* Hover effects on navigation items
* Smooth scrolling navigation
* Responsive design
* Home, About, Services, and Contact sections
* Service cards with hover effects
* Contact form interface

## Technologies Used

* HTML5
* CSS3
* JavaScript

1. Download or clone the repository.
